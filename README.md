# Telegram Web Proxy Installer by xanka

Удобный и полностью автоматический скрипт для развертывания безопасного **Telegram Web Proxy**. 
Этот тип прокси маскирует ваш Telegram-трафик под обычные веб-запросы (HTTPS/WebSocket) на стандартный порт `443`, что позволяет обходить даже жесткие блокировки (DPI), которые блокируют обычные MTProto-прокси.

## Особенности
- **Автоматическая установка и настройка**: Устанавливает Caddy, TProxy-Server и официальный MTProxy.
- **Всё в одной команде**: Больше не нужно отвечать на кучу вопросов. Скрипт сам сгенерирует надежный Secret и настроит SSL.
- **Маскировка**: Трафик выглядит как посещение обычного веб-сайта.
- **Защита от сканирования**: Если зайти на ваш домен через браузер откроется стандартная заглушка сайта.

## Требования
1. Сервер на Ubuntu или Debian (потребуется `root` доступ).
2. Привязанный к вашему серверу домен или поддомен (например, `proxy.example.com`), А-запись которого указывает на IP-адрес вашего сервера.
